# Professional Software Engineer Portfolio

A high-end, premium single-page portfolio website designed for software engineers to showcase their work, experience, and technical expertise. This version is optimized for professional presentation (CV/Resume attachment).

## 🚀 Key Features

- **Premium Design**: Uses a sophisticated color palette (Slate & Indigo) and modern typography (**Plus Jakarta Sans**).
- **Experience Timeline**: A dedicated section to showcase professional career progression—essential for recruiters.
* **Project Showcase**: High-impact project cards with tech badges and hover animations.
- **CV Integration**: Prominent "Download CV" call-to-action in the Hero section.
- **Modern UI Elements**: Features mesh gradients, glassmorphism, and smooth scroll animations.

## 🛠️ Technologies Used

- **HTML5** (Semantic structure)
- **Tailwind CSS** (Utility-first styling)
- **Font Awesome 6** (Premium iconography)
- **Google Fonts** (Typography)

## 🚀 How to Deploy / View

Since this is a static site, deployment is trivial.

1.  **Local Viewing**: Simply open `index.html` in any modern web 
2.  **GitHub Pages**: 
    - Push this folder to a GitHub repository.
    - Enable "Pages" in the repository settings.
3.  **Netlify / Vercel**: Drag and drop the folder into their deployment dashboards.

## 📝 Customization Guide

To make this your own:
1.  **Replace Name/Bio**: Edit the text in the `nav` and `hero` sections of `index.html`.
2.  **Update Experience**: Modify the timeline items in the `#about` section.
3.  **Add Projects**: Duplicate and edit the project card `div` blocks in the `#projects` section.
4.  **Change Colors**: Update the Tailwind classes (e.g., change `bg-indigo-600` to `bg-emerald-600`).
